# GREEN-API Web Chat (MAX / WhatsApp)

> Минималистичный веб-клиент для отправки и получения текстовых сообщений через **GREEN-API** с поддержкой мессенджера **MAX** и **WhatsApp**, разработанный в стиле дизайн-системы Apple.

Выполнено в качестве тестового задания на позицию **Frontend разработчик React** в компанию **GREEN-API**.

---

## 🚀 О проекте

Веб-приложение реализует полный цикл работы с API обмена сообщениями GREEN-API:
- Авторизация инстанса по `idInstance` и `apiTokenInstance`.
- Создание и выбор чата по номеру телефона получателя (включая международные форматы `79...` / `+7...` / `@c.us`).
- Отправка текстовых сообщений методом [`SendMessage`](https://green-api.com/v3/docs/api/sending/SendMessage/).
- Фоновое получение входящих сообщений в реальном времени через технологию [HTTP API](https://green-api.com/v3/docs/api/receiving/technology-http-api/):
  - Поллинг очереди через `ReceiveNotification` (таймаут 5 сек).
  - Мгновенное подтверждение обработки и очистка очереди методом `DeleteNotification`.
- Минималистичный интерфейс в стиле **Apple Messages / macOS / MAX Web** с поддержкой темной и светлой темы.

## 🛠 Стек технологий и архитектура

- **Фреймворк**: [Next.js](https://nextjs.org/) (App Router, Server & Client Components)
- **Библиотека интерфейса**: React 19
- **Язык**: TypeScript (строгая типизация всех ответов и запросов GREEN-API)
- **Стилизация**: Модульный Vanilla CSS с Apple Design Tokens (системные шрифты SF Pro, размытие backdrop-blur, адаптивная верстка, плавная анимация)
- **Иконки**: Lucide React

### Архитектурная структура

```
src/

│   ├── Sidebar.tsx        # Список диалогов, индикатор очереди, поиск и настройки
│   └── ChatWindow.tsx     # История сообщений, статусы отправки и поле ввода
├── context/
│   ├── AuthContext.tsx    # Управление сессией инстанса и сохранение в LocalStorage

```

## 📦 Быстрый локальный запуск

### 1. Клонирование и установка зависимостей

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd Green-API
npm install
```

### 2. Запуск в режиме разработки

```bash
npm run dev
```

Откройте в браузере: [http://localhost:3000](http://localhost:3000)

### 3. Сборка для продакшена

```bash
npm run build
npm run start
```

## 📱 Сценарий тестирования (по ТЗ)

1. **Авторизация**:
   - При первом открытии приложения откроется окно подключения.
   - Введите ваш **idInstance** и **apiTokenInstance** из [Личного кабинета GREEN-API](https://console.green-api.com/).
   - Нажмите **«Войти в чат»**. Учетные данные сохраняются локально в браузере.

2. **Создание чата**:
   - Нажмите кнопку **«+»** в левой панели.
   - Введите номер телефона собеседника (например, `79991234567` или в формате `+7 (999) 123-45-67`).
   - Нажмите **«Создать чат»**. Чат появится в списке и сразу откроется.

3. **Отправка сообщения**:
   - Введите текстовое сообщение в нижнее поле и нажмите `Enter` (или кнопку отправки).
   - Вызовется метод `POST /sendMessage`, и сообщение отобразится в чате с отметкой отправки.

4. **Получение ответа**:
   - Получатель отвечает в мессенджере (MAX или WhatsApp).
   - Фоновый процесс приложения получает входящее уведомление через `ReceiveNotification`, отображает сообщение в чате и сразу отправляет `DeleteNotification` для подтверждения.
