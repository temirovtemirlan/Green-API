# GREEN-API Web Chat

Клиент мессенджера для обмена сообщениями через REST API сервиса [GREEN-API](https://green-api.com/).

Проект выполнен в рамках тестового задания на позицию фронтенд-разработчика (React). В качестве визуального прототипа использован веб-интерфейс мессенджера MAX (web.max.ru).

---

## Реализованный функционал

### Основные требования ТЗ:
1. **Авторизация**:
   - Вход по `idInstance` и `apiTokenInstance`.
   - Проверка статуса инстанса через `getStateInstance`.
   - Сохранение сессии в `localStorage` (данные не сбрасываются при обновлении страницы).
   - Выход из аккаунта с очисткой сохранённых данных.

2. **Создание чата**:
   - Создание диалога по номеру телефона получателя.
   - Нормализация номеров любых форматов (`+7...`, `8...`, международные) в формат `@c.us`.

3. **Отправка сообщений**:
   - Отправка через метод [`sendMessage`](https://green-api.com/v3/docs/api/sending/SendMessage/).
   - Оптимистичное обновление UI: сообщение сразу появляется в переписке со статусом отправки.
   - Отправка по нажатию `Enter` (перенос строки — `Shift + Enter`).

4. **Получение входящих сообщений**:
   - Приём сообщений через HTTP API ([технология очередей](https://green-api.com/v3/docs/api/receiving/technology-http-api/)).
   - Фоновый цикл `receiveNotification` с таймаутом ожидания.
   - Моментальное подтверждение и удаление обработанного уведомления через `deleteNotification`.

### Дополнительно:
- Синхронизация существующих диалогов (`getChats`) и истории переписки (`getChatHistory`).
- Индикация статусов доставки сообщений (отправляется / отправлено / доставлено / прочитано).
- Поддержка воспроизведения входящих голосовых и аудио-сообщений.
- Адаптивный интерфейс: двухпанельный режим на десктопе и однопанельный режим с кнопкой «Назад» на мобильных экранах.

## Запуск проекта

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск локального сервера
```bash
npm run dev
```
Приложение откроется по адресу: [http://localhost:3000](http://localhost:3000)

### 3. Продакшен сборка
```bash
npm run build
npm run start
```

---

## Проверка работы

1. Открыть приложение в браузере.
2. Ввести `idInstance` и `apiTokenInstance` из личного кабинета GREEN-API и нажать «Войти».
3. Нажать кнопку создания нового чата (иконка в шапке слева) и указать номер телефона получателя.
4. Отправить текстовое сообщение.
5. При получении ответного сообщения оно отобразится в чате в режиме реального времени.
