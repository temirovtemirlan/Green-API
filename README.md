# GREEN-API Chat — Тестовое задание

Веб-клиент мессенджера для отправки и приёма сообщений WhatsApp через REST API сервиса [GREEN-API](https://green-api.com/).

Разработано в качестве выполнения тестового задания на позицию Frontend-разработчика.

---

## 🎯 Реализованные требования ТЗ

1. **Авторизация по инстансу**:
   - Ввод `idInstance` и `apiTokenInstance` из личного кабинета GREEN-API.
   - Проверка статуса инстанса (`getStateInstance`) перед входом.
   - Сохранение сессии в `localStorage` (не нужно вводить заново при обновлении страницы).
   - Кнопка выхода из системы с полной очисткой локальных данных.

2. **Создание чата**:
   - Создание диалога по номеру телефона получателя.
   - Автоматическая нормализация любых форматов номера (`+7 999 123-45-67`, `8999...`, `7999...` → `79991234567@c.us`).

3. **Отправка сообщений**:
   - Метод `sendMessage`.
   - Оптимистичное обновление интерфейса: сообщение мгновенно появляется в списке с индикатором отправки, затем статус обновляется.
   - Отправка по нажатию `Enter` (с переносом строки по `Shift + Enter`).

4. **Получение входящих сообщений в реальном времени**:
   - Реализована работа с HTTP-очередью GREEN-API:
     - Фоновый цикл long-polling через `receiveNotification` (с таймаутом ожидания).
     - Мгновенное подтверждение и очистка очереди через `deleteNotification` сразу после обработки события.
     - Корректная обработка отключения и остановка цикла при размонтировании (`AbortController`).

## ⚡️ Что реализовано дополнительно (сверх базового ТЗ)

Чтобы интерфейс ощущался как полноценный рабочий мессенджер, были добавлены следующие возможности:

- **Синхронизация существующих чатов** (`getChats`): при входе в систему подтягиваются активные диалоги с привязанного WhatsApp-аккаунта.
- **История сообщений** (`getChatHistory`): при открытии чата подгружаются предыдущие сообщения.
- **Статусы сообщений** (`outgoingMessageStatus`): отслеживание этапов *отправляется* 🕒 → *отправлено* ✓ → *доставлено* ✓✓ → *прочитано* (синие галочки).
- **Синхронизация прочтения** (`readChat`): при открытии диалога запрос отправляется на сервер GREEN-API, чтобы сообщения помечались прочитанными и в реальном WhatsApp.
- **Инфо о контакте** (`getContactInfo`): отображение имени, статуса последней активности («в сети» / время визита) и аватарок.
- **Поддержка медиа и голосовых**: корректное отображение входящих аудио-сообщений, изображений и документов.
- **Счетчик непрочитанных**: индикация новых входящих сообщений во время активной сессии и плашка первого непрочитанного сообщения в диалоге.
- **Адаптивный дизайн**: чистый современный UI, поддержка мобильных экранов и десктопа.

## 🛠 Стек технологий

- **Next.js 15** (App Router, Client Components)
- **React 19**
- **TypeScript** (строгая типизация всех ответов и полезных нагрузок GREEN-API)
- **Tailwind CSS** (кастомная верстка без тяжелых UI-китов)
- **Solar Icons** (`@solar-icons/react`)
- **Framer Motion** (`motion`) для плавных переходов и анимаций

## 📁 Структура проекта

```
src/
├── app/
│   ├── layout.tsx         # Корневой layout, шрифты, метатеги
│   ├── page.tsx           # Главная страница: переключение между авторизацией и чатом

├── components/
│   ├── AuthScreen.tsx     # Экран ввода idInstance / apiTokenInstance
│   ├── Sidebar.tsx        # Список чатов, поиск, кнопка создания диалога и выход
│   ├── ChatWindow.tsx     # Окно сообщений, статусы доставки, поле ввода
│   ├── NewChatModal.tsx   # Модальное окно создания нового чата по номеру
│   └── VoiceNote.tsx      # Компонент воспроизведения голосовых сообщений
├── context/
│   ├── AuthContext.tsx    # Управление состоянием авторизации и кредами
│   └── ChatContext.tsx    # Работа с чатами, отправка, long-polling очереди уведомлений
├── services/
│   └── greenApiClient.ts  # Класс-клиент для взаимодействия с методами GREEN-API
└── types/
    └── greenApi.ts        # Типы данных GREEN-API (запросы, вебхуки, сообщения)
```

## 🚀 Локальный запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/temirovtemirlan/Green-API.git
cd Green-API
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Запуск dev-сервера

```bash
npm run dev
```

Приложение будет доступно по адресу: [http://localhost:3000](http://localhost:3000)

### 4. Сборка продакшен-версии

```bash
npm run build
npm run start
```

## 🧪 Сценарий проверки

1. Откройте приложение в браузере.
2. Введите ваши данные из [консоли GREEN-API](https://console.green-api.com/):
   - `idInstance` (например: `1101...`)
   - `apiTokenInstance` (например: `d79b...`)
3. Нажмите **«Войти»**. При успешной проверке откроется основной интерфейс чата.
4. Нажмите кнопку **«+»** в панели слева и введите номер телефона контакта, которому хотите написать.
5. Напишите текст и отправьте — сообщение уйдёт получателю в WhatsApp.
6. Отправьте ответное сообщение с телефона контакта — оно появится в веб-чате через фоновый long-polling.
